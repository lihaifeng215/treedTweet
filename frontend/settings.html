配置 OpenAI 兼容格式的大模型接口，用于生成热点监控数据与高质量公众号文章。支持 OpenAI、DeepSeek、本地 Ollama 等。

🔑 接口设置

密钥仅保存在本地服务器（config.json），不会上传到任何第三方。

兼容 OpenAI 的接口基地址。例如：
· Agnes：https://apihub.agnes-ai.com/v1
· DeepSeek：https://api.deepseek.com/v1
· 本地 Ollama：http://localhost:11434/v1

可选。HTTP/HTTPS 代理地址，用于访问被限制的 API（如国内访问 OpenAI）。填写后可解决连接超时问题。

如 gpt-4o-mini、deepseek-chat、qwen-max 等。

越高越有创意，越低越稳定（0–2）。

⚡ 高级功能

启用 SSE 流式生成文章

开启后推文将逐步显示，实时感受 AI 创作过程。

启用深度推理模式

适用于复杂分析，模型会先思考再回答，消耗更多 Token。

思考模式最大 Token 数。常规任务 2048 即可，复杂任务可调高。

公众号文章的建议篇幅，可根据需求调整。影响所有风格文章的生成篇幅。

🔍 搜索引擎配置

用于渐进式创作工作流的「搜索调研」步骤。默认使用 Bing HTML 抓取（免费，国内友好），无需额外配置。

仅 SerpAPI/Bing API 需要。DuckDuckGo / Bing HTML 留空即可。

可选。用于自建搜索代理或兼容其他搜索引擎。

ℹ️ 使用说明

  • 热点数据来自 Hacker News、B站热门、百度热搜、头条热榜、抖音热榜、GitHub Trending、微博热搜的真实接口（手动刷新抓取）。
  • 公众号文章由你配置的大模型实时生成，支持 4 种风格：专业深度 / 幽默风趣 / 悬念吸引 / 情感共鸣。
  • 「分析热点」功能会调用大模型生成结构化监控数据（摘要、关键点、情感、趋势等）。
  • 也可通过环境变量配置（更适合生产）：LLM_API_KEY、LLM_BASE_URL、LLM_MODEL、LLM_TEMPERATURE。
